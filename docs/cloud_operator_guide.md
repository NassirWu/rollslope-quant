# RollSlope Quant MVP — 雲端網頁版操作說明

給非技術人員閱讀，不會談到程式碼架構、測試工具或版本控制，只說怎麼用。

## 這個雲端版是什麼？

- 這是部署在 Streamlit Community Cloud 上的網頁版，有一個固定的網址。
- **不需要開本機電腦**，也**不需要**和電腦連同一個 Wi-Fi。
- 只要手機或電腦能上網，點開網址就能使用，運算在雲端伺服器上進行。

## 使用前準備

- 拿到工程人員提供的雲端網址。
- 不需要券商憑證。
- 不需要金鑰。
- 不需要安裝任何東西。

## 怎麼打開？

在手機或電腦的瀏覽器網址列輸入拿到的雲端網址，直接打開即可操作，不需要額外登入。

## 雲端上可以做什麼？

- **跑 Demo**：直接使用內建的範例資料，按一下「計算」就能看到結果。
- **手動輸入 X/Y**：在畫面上的表格直接修改數字，按「計算」。
- **上傳 CSV**：把手機或電腦裡的 CSV 檔案上傳，選好欄位後按「計算」。
- **下載結果 CSV**：計算完成後可以按「下載結果 CSV」把結果存到手機或電腦。

## X 是什麼？Y 是什麼？

- **X**：代表資料的先後順序，例如第 1 筆、第 2 筆…，或是時間軸。
- **Y**：代表你想觀察的數值，例如價格。

## 怎麼看結果？

計算完成後，畫面會顯示一整張表格，以及「最後一列重點」，裡面包含：

- **t1 / t2 / t3**、**z1 / z2 / z3**：代表資料前段、中段、後段的斜率變化程度。
- **breakpoint_1 / breakpoint_2**：代表趨勢轉折的位置。
- **r_squared**：代表這個計算結果的擬合程度，數字愈接近 1 代表愈準確。
- **is_valid**：代表這筆結果有沒有達到預先設定的準確門檻，`True` 代表合格，`False` 代表不合格。

## 風控限制（請務必了解）

本雲端版本只做斜率模型計算：

- 不連接任何券商
- 不放任何金鑰
- 不做真實資金操作
- 畫面上看到的所有結果僅供研究參考

## 給部署人員的步驟（Streamlit Cloud 部署）

1. 確認專案已經推到 GitHub。
2. 打開 share.streamlit.io，用 GitHub 帳號登入。
3. 點「New app」，選擇這個 repo 和分支（例如 `main`）。
4. 在「Main file path」欄位填入：`cloud/app.py`
5. 按「Deploy」，等待幾分鐘讓它建置完成。
6. **重要：Secrets 欄位請保持空白，不要填任何東西。** 本專案雲端版不需要任何密鑰或設定值。
7. 建置完成後會拿到一個網址，把這個網址分享給要使用的人即可。

## 常見問題

- **第一次打開很慢**：Streamlit Cloud 免費方案若閒置一段時間會進入休眠，重新打開網址時需要等待喚醒，稍等即可。
- **畫面顯示錯誤**：請重新整理網頁，或確認上傳的 CSV 格式是否正確。
- **CSV 欄位名稱錯誤**：請確認上傳的 CSV 第一列是欄位名稱，並在畫面上選對 X 欄位和 Y 欄位。
- **資料不足**：資料的筆數必須大於或等於設定的 window_size，資料太少時請減少 window_size 或補齊資料。
- **數字欄位有空白**：請確認 X 欄位和 Y 欄位裡每一格都有填數字，不要留空白或打錯字。
