# RollSlope Quant MVP — 手機網頁版操作說明

給非技術人員閱讀，不會談到程式碼架構、測試工具或版本控制，只說怎麼用。

## 這個手機版是什麼？

- 這**不是**手機 App，不需要到商店下載安裝。
- 這是一個「手機瀏覽器可以打開的網頁畫面」。
- 真正的運算是在電腦上進行，手機只是負責顯示畫面和操作。

## 使用前準備

- 電腦已經有工程人員裝好這個專案的環境。
- 手機和電腦必須連接**同一個 Wi-Fi**。
- 不需要券商憑證。
- 不需要金鑰。
- 不需要安裝 Ollama 或任何 AI 模型。

## 啟動方式

1. 在電腦上，找到專案資料夾裡的 `run_mobile_web.bat`，雙擊它。
2. 會跳出一個黑色視窗，等它顯示出兩行網址，類似：
   - `Local URL: http://localhost:8501`
   - `Network URL: http://192.168.x.x:8501`
3. 在手機瀏覽器（例如 Safari、Chrome）網址列輸入畫面上顯示的 **Network URL**，打開即可操作。
4. 這個黑色視窗請保持開著，關掉視窗＝服務停止，手機就打不開畫面了。

## 手機上可以做什麼？

- **跑 Demo**：直接使用內建的範例資料，按一下「計算」就能看到結果。
- **手動輸入 X/Y**：在畫面上的表格直接修改數字，按「計算」。
- **上傳 CSV**：把手機或電腦裡的 CSV 檔案上傳，選好欄位後按「計算」。
- **下載結果 CSV**：計算完成後可以按「下載結果 CSV」把結果存到手機或電腦。

## X 是什麼？Y 是什麼？

- **X**：代表資料的先後順序，例如第 1 筆、第 2 筆…，或是時間軸。
- **Y**：代表你想觀察的數值，例如價格。

## 怎麼看結果？

計算完成後，畫面會顯示一整張表格，以及「最後一列重點」，裡面包含：

- **t1 / t2 / t3**、**z1 / z2 / z3**：代表資料前段、中段、後段的斜率變化程度。
- **breakpoint_1 / breakpoint_2**：代表趨勢轉折的位置。
- **r_squared**：代表這個計算結果的擬合程度，數字愈接近 1 代表愈準確。
- **is_valid**：代表這筆結果有沒有達到預先設定的準確門檻，`True` 代表合格，`False` 代表不合格。

本工具只做斜率模型計算，**不會買賣、不會自動下單、不會操作真實資金**。

## 常見問題

- **手機打不開網址**：確認手機和電腦是不是連同一個 Wi-Fi，並確認網址有沒有打錯（要用畫面顯示的 Network URL，不是 Local URL）。
- **防火牆阻擋**：第一次啟動時，Windows 可能會跳出防火牆詢問視窗，請選擇「允許」。
- **手機和電腦不在同一 Wi-Fi**：請把兩者切換到同一個無線網路後再試一次。
- **黑色視窗關掉後手機不能用了**：這是正常現象，因為服務已經停止，重新雙擊 `run_mobile_web.bat` 再打開一次即可。
- **CSV 欄位名稱錯誤**：請確認上傳的 CSV 第一列是欄位名稱，並在畫面上選對 X 欄位和 Y 欄位。
- **資料不足**：資料的筆數必須大於或等於設定的 window_size，資料太少時請減少 window_size 或補齊資料。
- **數字欄位有空白**：請確認 X 欄位和 Y 欄位裡每一格都有填數字，不要留空白或打錯字。
